# Programmering för testare – Inlämningsuppgift

Detta repository innehåller min individuella inlämningsuppgift i kursen **Programmering för testare** på YH-utbildningen **Mjukvarutestare, klass MVT26 Stockholm** vid EC Utbildning.

Kurs: Programmering för testare

## Om programmet

Programmet läser in text rad för rad från kommandoraden tills användaren skriver stop.

Programmet räknar bland annat antal rader och antal tecken. Logiken ligger i en separat klass och funktionaliteten testas med JUnit.
